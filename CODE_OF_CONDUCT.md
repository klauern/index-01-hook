# Code of Conduct

## Expected behavior

Contributors and maintainers must:

- Treat people with respect.
- Use clear, factual, and constructive language.
- Welcome different backgrounds and technical views.
- Focus criticism on ideas, code, and behavior.
- Protect private information and credentials.
- Follow project instructions and GitHub rules.

## Unacceptable behavior

The project does not accept:

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or unwanted sexual attention.
- Doxxing or publication of private information.
- Publication of credentials, private payloads, or provider data.
- Deliberate disruption, impersonation, or abuse of project resources.
- Retaliation against a person who makes a good-faith report.

## Reporting and enforcement

For conduct on GitHub, use GitHub content-reporting tools for the relevant
issue, pull request, comment, or other content. Do not post private details in
a public issue.

For a private project report, use the repository owner's GitHub contact method:
<https://github.com/klauern>. Include only the minimum safe information.

Maintainers will review reports as privately as possible. Maintainers may
remove content, issue a warning, restrict participation temporarily or
permanently, or close an issue or pull request. Maintainers may also refer a
matter to GitHub or the appropriate authority when required.

This document defines project behavior rules. It does not replace GitHub's
terms, policies, or content-reporting process.
