# Security

## Supported versions

Security support covers only the latest non-prerelease GitHub Release.
Older releases, prereleases, modified source, and modified images are not
supported.

## Report a vulnerability

Use GitHub private vulnerability reporting after source publication:

<https://github.com/klauern/index-01-hook/security/advisories/new>

The URL becomes active with the public repository. A pre-publication worktree
is not a supported release.

Do not report vulnerabilities through public issues. Do not publish exploit
details before the project has assessed the report.

Include these details in the private report:

- The affected release version or source revision.
- The deployment method.
- Reproduction steps that use synthetic data.
- The possible security impact.
- Redacted logs or other evidence that helps confirm the issue.

Do not include secrets, transcription text, item content, request or response
headers, or provider request and response bodies. Remove tokens, identifiers,
private URLs, and personal data from every attachment.

The maintainers will review each private report. The project does not promise a
response deadline.
